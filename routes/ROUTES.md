# Маршруты School Days (порт Ren'Py 8.2.1): 22 концовки

Всё посчитано по настоящему AST игры (движок сам загрузил все 1881 скрипт), а не регулярками. Каждый маршрут затем **прогнан настоящим движком** с автопилотом: движок сам выполнял условия, прыжки и очки, автопилот только подставлял ответы. Сверялся каждый показанный набор вариантов (если бы текст не совпал, прогон падал бы с MISMATCH) и итоговая концовка sdendN.

Файл на концовку читай по ходу игры: «[код сцены] какой вариант». Вариант считается сверху вниз: 1, 2. **«Промолчать»** = клавиша `0` в этом порте (это значит lastB = −1, отдельная ветка). Если в строке написано ВАЖНО, любой другой вариант (без промолчать) уводит от этой концовки, это доказано исчерпывающим перебором.

## Ветка KF (Котоноха в отеле) отдельно

- [KF_к_концовке_16_SB_I02.txt](KF_к_концовке_16_SB_I02.txt) → концовка 16 (SB_I02)
- [KF_к_концовке_07_B0_F00.txt](KF_к_концовке_07_B0_F00.txt) → концовка 7 (B0_F00)

В KF ветвится на `05_05_KF_G00`: проверка `var001 > var002` (у Сэкаи больше очков, чем у Котонохи) стоит на пути в SB_E01 (в маршруте у Сэкаи 94, у Котонохи 76). Этот шаг в старой шпаргалке отсутствовал. Подробно: см. раздел KF.

## Быстрая проверка вручную (подтверждено прогоном)

Положи `renpy/routes_start.rpy` в `game/` своей копии. Включение:

```bash
tools/start_at.sh end15
```

После этого «Новая игра» стартует не с начала, а с первой сцены 4-й главы с нужными очками и флагами (для KF ещё есть `kf15_late`, `kf16_late`, `kf7_late`: старт прямо в `KF_A00`). Дальше жми варианты из файла маршрута, начиная с шага, который идёт после этой точки. Выключить:

```bash
tools/start_at.sh off
```

Каждая точка прогнана: оставшиеся выборы маршрута приводят в ту самую концовку (28 из 28 точек). Саму механику `routes_start` (файл + подмена метки `start`) тоже прогнал на `kf15_late` движком: пришёл в концовку 15.

Полный список точек: `end0`, `end1`, `end2`, `end3`, `end4`, `end5`, `end6`, `end7`, `end8`, `end9`, `end10`, `end11`, `end12`, `end13`, `end14`, `end15`, `end16`, `end17`, `end18`, `end19`, `end20`, `end21`, `kf15`, `kf15_late`, `kf16`, `kf16_late`, `kf7`, `kf7_late`.

## Честно: что и как проверено, чего нет

- Таймеры: в игре на экране выбора таймер растянут, ответ только твой (ты сам нажимаешь). Маршруты не полагаются на таймаут.
- Маршруты не единственные: на многих шагах можно ответить иначе и всё равно прийти к концовке, но очки поменяются. Список даёт один проверенный путь, ВАЖНО помечает развилки, где иначе нельзя (для трёх KF-файлов эту разметку не считал).
- Возможность другого пути при «промолчать»: перебор «нельзя» в файлах считался без «0». Где «0» нужен в маршруте, он явно записан.
- `var000` в условиях нигде не используется, поэтому в точках старта его нет.
